# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **security@usewarp.net** and include:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- Any affected versions, URLs, or commits

We will acknowledge your report within 72 hours and keep you updated while we investigate. Please give us a reasonable amount of time to fix the issue before disclosing it publicly.

## Scope

This policy covers the code in this repository and the services hosted under `usewarp.net`.
